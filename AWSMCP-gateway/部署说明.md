# aws-mcp 单入口改造（MCP 网关 + ALB Entra ID 认证）

## 目标架构

```
Copilot Studio ─(一次 OAuth)─► Cloudflare ─► ALB  https://clade.dev.lilly.cn/mcp
                                            │  tg-00：jwt-validation（iss / exp / aud / scp=mcp.access）
                                            ▼
                                   ecssvc-00  MCP 网关（mcp-gateway）
                                    ├─ http://aws-api:8000/mcp ─► ecssvc-01 aws-api（内网，无 ALB）
                                    └─ http://aws-doc:8000/mcp ─► ecssvc-02 aws-doc（内网，无 ALB）
                                       （ECS Service Connect，命名空间 lly-nw-cloudops-awsmcp-d）
```

## 部署顺序（Dev 环境，切换期间 MCP 短暂不可用）

1. **新建基础资源**：ecr-00、cwlg-00、gw-d-sg-01。
2. **构建网关镜像**：用 mcp-gateway 目录构建并推送到 ecr-00，记下 tag（sha-xxxx）。
3. **更新 ecs-01**：创建命名空间并设为集群默认。
4. **更新 ecssvc-01、ecssvc-02**：去掉 ALB、开启 Service Connect。
   - 先看 Change Set：rService 应为 Modify。若显示 Replacement，因 ServiceName 固定会更新失败，需要先删除该 stack 再按新模板创建。
5. **删除 tg-01、tg-02 两个 stack**（必须在第 4 步之后，否则 ecssvc 仍引用其导出值，删除会被拒绝）。
6. **更新 ecs-d-sg-01**：入站改为来自网关 SG（依赖第 1 步的导出值）。
7. **新建 tg-00**（pAuthMode = jwt）。
8. **新建 ecssvc-00**：pImageTag = 第 2 步的 tag，pDesiredCount = 1。

## 验证

```bash
H=https://clade.dev.lilly.cn
curl -s -o /dev/null -w "%{http_code}\n" -X POST $H/mcp            # 401（无 Token，ALB 拒绝）
curl -s -o /dev/null -w "%{http_code}\n" -X POST $H/mcp -H "Authorization: Bearer abc"   # 401
curl -s -o /dev/null -w "%{http_code}\n" $H/aws-api/mcp            # 404（旧路径已下线）
curl -s -o /dev/null -w "%{http_code}\n" $H/healthz                # 404（/healthz 不对外，只供目标组健康检查）
```

- 目标组 tg-00 中网关 Target 为 healthy。
- 网关日志 /aws/ecs/lly-nw-cloudops-awsmcp-d-cwlg-00 无 backend 连接错误。
- mcp.access 管理员同意完成后，在 Copilot Studio 测试窗口登录一次，工具列表出现 aws_api_* 和 aws_doc_* 两组工具。

## 回退

- 认证问题：tg-00 的 pAuthMode 改为 none 仅用于排查，排查完立即改回 jwt。
- 整体回退：用原模板重新部署 tg-01/02、ecssvc-01/02、ecs-d-sg-01，删除 tg-00、ecssvc-00。

## 部署前确认

- 部署用的 CI 角色要有 servicediscovery（CreateHttpNamespace、TagResource 等）和 ECS Service Connect 相关权限。
- cn-northwest-1 控制台的规则动作里有 Validate token（jwt-validation）。
- Entra JWKS 的 key 数不超过 10、响应不超过 150 KB（超出时 ALB 停止转发）。
- requirements.txt 中 fastmcp 先在本地测试，再固定到具体版本。
- Copilot Studio 的服务器 URL 保持 https://clade.dev.lilly.cn/mcp，Entra 重定向 URL 不变。
